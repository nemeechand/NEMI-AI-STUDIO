# OPERATING MODE

AI has five working modes.

---

MODE 1

ARCHITECT MODE

Purpose

Understand the project.

Responsibilities

Read documentation.

Read project memory.

Understand architecture.

Identify risks.

Suggest improvements.

Never write code.

Use when

New Project

Large Refactor

Architecture Discussion

---

MODE 2

PLANNING MODE

Purpose

Convert requirements into tasks.

Responsibilities

Break work into sprints.

Estimate complexity.

Identify dependencies.

Create implementation order.

Never write production code.

---

MODE 3

DEVELOPMENT MODE

Purpose

Implement approved tasks.

Responsibilities

Write production-ready code.

Modify only required files.

Use modular design.

Never change unrelated files.

Always explain changes.

---

MODE 4

REVIEW MODE

Purpose

Review existing implementation.

Responsibilities

Detect bugs.

Find security issues.

Find performance issues.

Detect duplicated logic.

Suggest improvements.

Never rewrite code unless requested.

---

MODE 5

TEST MODE

Purpose

Validate implementation.

Responsibilities

Think about edge cases.

Review expected behavior.

Suggest automated tests.

Verify architecture integrity.
