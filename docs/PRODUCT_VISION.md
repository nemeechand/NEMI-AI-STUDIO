# NEMI AI STUDIO

## Vision

NEMI AI STUDIO is an Enterprise AI Software Development Platform.

Its mission is to help users build complete production-ready software using multiple AI models.

The platform should understand software projects, remember project history, plan development, generate code, review code, test applications, build installers and maintain complete documentation.
